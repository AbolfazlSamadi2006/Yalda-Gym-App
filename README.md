# 🏋️ نرم‌افزار مدیریت باشگاه بدنسازی و برنامه‌ریزی ورزشی - یلدا (Yalda)

نرم‌افزار جامع، مدرن و کاملاً فارسی **یلدا (Yalda)** جهت مدیریت کامل باشگاه‌های ورزشی و بدنسازی، ثبت پرونده ورزشکاران، ارزیابی آنتروپومتریک فیزیکی، مدیریت مدارک پزشکی چندصفحه‌ای و ساخت هوشمند برنامه‌های تمرینی و غذایی همراه با قابلیت صدور فایل PDF استاندارد.

---

## ✨ قابلیت‌های کلیدی نرم‌افزار

- 🔐 **احراز هویت و ورود ایمن:** سیستم لاگین فول‌اسکرین با امکان ویرایش نام کاربری/پسورد و بازیابی اضطراری مربی.
- 👥 **مدیریت کامل ورزشکاران:** ثبت، ویرایش، حذف پرونده جامع اعضا همراه با عکس پروفایل اختصاصی و فرم‌های فشرده و بهینه.
- 📁 **ثبت و مدیریت مدارک پزشکی چندصفحه‌ای:** امکان آپلود عکس و فایل‌های PDF چندصفحه‌ای آزمایشات و مدارک پزشکی، همراه با نماشگر اختصاصی، قابلیت زوم و چرخش صفحات.
- 📏 **ارزیابی آنتروپومتریک و سنجش فیزیکی:** ثبت قد، وزن، درصد چربی عضلانی، دور سینه، بازو، ران و سوابق تغییرات همراه با قابلیت ویرایش و حذف سوابق.
- 📸 **مقایسه بصری قبل و بعد (Before & After):** نمایشگر اختصاصی عکس‌های تغییرات فیزیکی قبل و بعد ورزشکاران جهت پایش دقیق روند پیشرفت.
- 🥗 **برنامه‌ریزی هوشمند تغذیه و رژیم ایرانی:**
  - چیدمان منسجم و استاندارد ۲ ردیفه برای اهداف فیزیکی و درشت‌مغذی‌ها.
  - فیلدهای سفید و آماده نوشتن (بدون مقادیر پیش‌فرض مزاحم).
  - محاسبه آنی و هوشمند درصد درشت‌مغذی‌ها (پروتئین، کربوهیدرات، چربی) و گرم کل.
  - ریست کامل و خودکار تمامی فیلدها و جدول‌ها پس از ذخیره الگو یا ورود مجدد به صفحه.
- 🏋️ **برنامه‌ریزی هوشمند تمرینی:**
  - برنامه‌ریزی ۱ تا ۶ روز در هفته با جدول‌های تمیز و بدون ردیف پیش‌فرض اولیه (افزایش حرکات به انتخاب مربی).
  - ذخیره الگوها در بانک و بارگذاری آنی الگوهای آماده.
- 🏃 **بانک جامع حرکات ورزشی و مواد غذایی:** افزودن و مدیریت حرکات به همراه تصویر یا ویدیو آموزشی (MP4/PNG) و مواد غذایی با ارزش غذایی دقیق.
- 📄 **صدور خروجی PDF:** تولید برنامه‌های تمرینی و غذایی به صورت فایل PDF فارسی، شکیل و آماده چاپ.
- 🎨 **طراحی UI/UX مدرن و زیبا:** تم تاریک اختصاصی (Dark-Red)، دکمه‌های اکشن رنگی (ویرایش طلایی، حذف قرمز، پروفایل دودی)، و دکمه خروج قرمز.
- 💾 **پشتیبان‌گیری و بازگردانی دیتابیس:** فایل پشتیبان خودکار دیتابیس جهت حفظ ایمن تمام اطلاعات.

---

## 🛠️ تکنولوژی‌های استفاده‌شده

- **زبان برنامه‌نویسی:** Python 3.10+
- **رابط کاربری:** PyQt6 (طراحی RTL فارسی با تم Dark-Red شکیل)
- **پایگاه داده:** SQLite با SQLAlchemy ORM
- **گزارش‌گیری:** ReportLab (تولید PDF فارسی)
- **پردازش تصویر و مدارک:** PyMuPDF / Pillow
- **بسته‌بندی اجرایی:** PyInstaller (ایجاد نسخه Standalone `.exe`)

## 🚀 راهنمای دانلود و اجرای مستقیم (.exe) روی سیستم مربی

برای اجرای برنامه روی لپ‌تاپ مربی **بدون نیاز به نصب هیچ نرم‌افزار پیش‌نیازی**:

۱. به بخش **[Releases](https://github.com/AbolfazlSamadi2006/Yalda-Gym-App/releases)** در گیت‌هاب مراجعه کنید.
۲. آخرین نسخه **`Yalda_v1.0.zip`** را دانلود کنید.
۳. پوشه را از حالت فشرده خارج (Extract) کرده و روی **`Yalda.exe`** دبل کلیک کنید.

---

## 👨‍💻 راهنمای نصب و اجرا در محیط توسعه (برای توسعه‌دهندگان)

۱. مخزن را کلون کنید:
```bash
git clone https://github.com/AbolfazlSamadi2006/Yalda-Gym-App.git
cd Yalda-Gym-App
```

۲. محیط مجازی ساخت و فعال کنید:
```bash
python -m venv venv
# در ویندوز:
.\venv\Scripts\activate
```

۳. کتابخانه‌های مورد نیاز را نصب کنید:
```bash
pip install PyQt6 SQLAlchemy reportlab PyMuPDF Pillow pyinstaller
```

۴. برنامه را اجرا کنید:
```bash
python main.py
```

---

## 📦 ساخت فایل اجرایی مستقل (.exe)

جهت ساخت فایل خروجی قابل اجرا:
```bash
pyinstaller --name="Yalda" --noconsole --onedir --add-data "resources;resources" --noconfirm main.py
```
خروجی در پوشه `dist/Yalda/Yalda.exe` قرار خواهد گرفت.
