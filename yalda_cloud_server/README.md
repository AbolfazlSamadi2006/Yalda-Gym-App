# ☁️ راهنمای سرور ابری پشتیبان‌گیری یلدا (Yalda Cloud Backup Server)

این سرور اختصاصی جهت دریافت، ذخیره‌سازی، دسته‌بندی و مانیتورینگ آنلاین پایگاه‌داده‌های نرم‌افزار باشگاه یلدا توسعه داده شده است.

---

## 🌟 امکانات سامانه:
1. **دریافت خودکار بک‌آپ‌ها:** با شناسه یکتای شماره موبایل هر مربی (phone).
2. **جلوگیری از اشغال فضا:** هر بک‌آپ جدید جایگزین نسخه قبلی همان مربی می‌شود تا فضای سرور بهینه بماند.
3. **امنیت بالا:** ارتباط با توکن امنیتی اختصاصی (X-API-Key).
4. **پنل مدیریت تحت‌وب زیبا:** با تم تاریک/قرمز باشگاه یلدا، نمایش کارت‌های آمار و دکمه دانلود ۱-کلیک دیتابیس مربیان.

---

## 🚀 روش‌های راه‌اندازی و استقرار:

### روش اول: استقرار ۱۰۰٪ رایگان و ابری روی Render.com (پیشنهادی ⭐️)
1. در سایت [Render.com](https://render.com) یک حساب رایگان ایجاد کنید.
2. پوشه yalda_cloud_server را در یک مخزن جدید در گیت‌هاب خود آپلود کنید.
3. در پنل Render، دکمه **New +** را زده و **Web Service** را انتخاب کنید و مخزن گیت‌هاب را متصل نمایید.
4. تنظیمات به صورت خودکار از ender.yaml خوانده شده و سرور در کمتر از ۲ دقیقه آنلاین می‌شود!
5. آدرس اینترنتی دریافت شده از رندر (مثلاً https://yalda-cloud.onrender.com) را در صورت تمایل می‌توانید در فایل config.py نرم‌افزار تنظیم کنید.

### روش دوم: اجرای لوکال در کامپیوتر یا سرور مجازی (VPS)
1. با اجرای فایل start_server.bat یا دستور زیر در ترمینال:
   `ash
   pip install -r requirements.txt
   uvicorn server:app --host 0.0.0.0 --port 8000
   `
2. پنل مدیریت در آدرس: http://localhost:8000 در دسترس خواهد بود.
