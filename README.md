# 🏋️ نرم‌افزار مدیریت باشگاه بدنسازی و برنامه‌ریزی ورزشی - یلدا (Yalda)

![Yalda Gym App](resources/images/arrow_down.svg)

نرم‌افزار جامع، مدرن و کاملاً فارسی **یلدا (Yalda)** جهت مدیریت کامل باشگاه‌های ورزشی و بدنسازی، ثبت پرونده ورزشکاران، ارزیابی فیزیکی و ساخت هوشمند برنامه‌های تمرینی و غذایی همراه با قابلیت صدور فایل PDF استاندارد.

---

## ✨ قابلیت‌های کلیدی نرم‌افزار

- 🔐 **احراز هویت و ورود ایمن:** سیستم لاگین فول‌اسکرین با امکان ویرایش نام کاربری/پسورد و بازیابی اضطراری مربی.
- 👥 **مدیریت کامل ورزشکاران:** ثبت، ویرایش، حذف پرونده جامع اعضا همراه با عکس پروفایل اختصاصی.
- 📋 **سوابق پزشکی و آسیب‌دیدگی‌ها:** ثبت سوابق فیزیکی، منع مصرف حرکات و هشدارهای هوشمند هنگام برنامه‌ریزی.
- 🏃 **بانک جامع حرکات ورزشی:** امکان اضافه کردن، ویرایش و حذف حرکات به همراه تصویر یا ویدیو آموزشی (MP4/PNG) و پخش مستقیم.
- 🥗 **بانک مواد غذایی:** ثبت و مدیریت مواد غذایی و ارزش غذایی (کالری، پروتئین، کربوهیدرات و چربی).
- 🏋️ **برنامه‌ریزی هوشمند تمرینی و غذایی:** طراحی برنامه‌های تخصصی، ذخیره الگوها در بانک و بارگذاری آنی الگوهای آماده.
- 📄 **صدور خروجی PDF:** تولید برنامه‌های تمرینی و غذایی به صورت فایل PDF فارسی، شکیل و آماده چاپ.
- 💾 **پشتیبان‌گیری و بازگردانی دیتابیس:** فایل پشتیبان خودکار دیتابیس جهت حفظ ایمن تمام اطلاعات.

---

## 🛠️ تکنولوژی‌های استفاده‌شده

- **زبان برنامه‌نویسی:** Python 3.10+
- **رابط کاربری:** PyQt6 (طراحی RTL فارسی با تم Dark-Red شکیل)
- **پایگاه داده:** SQLite با SQLAlchemy ORM
- **گزارش‌گیری:** ReportLab (تولید PDF فارسی)
- **بسته‌بندی اجرایی:** PyInstaller (ایجاد نسخه Standalone `.exe`)

---

## 🚀 راهنمای نصب و اجرا در محیط توسعه

۱. مخزن را کلون کنید:
```bash
git clone https://github.com/USERNAME/yalda-gym-app.git
cd yalda-gym-app
```

۲. محیط مجازی ساخت و فعال کنید:
```bash
python -m venv venv
# در ویندوز:
.\venv\Scripts\activate
```

۳. کتابخانه‌های مورد نیاز را نصب کنید:
```bash
pip install PyQt6 SQLAlchemy reportlab pyinstaller
```

۴. برنامه را اجرا کنید:
```bash
python main.py
```

---

## 📦 ساخت فایل اجرایی مستقل (.exe)

جهت ساخت فایل خروجی قابل اجرا بدون نیاز به پایتون:
```bash
pyinstaller --name="Yalda" --noconsole --onedir --add-data "resources;resources" --noconfirm main.py
```
خروجی در پوشه `dist/Yalda/Yalda.exe` قرار خواهد گرفت.
